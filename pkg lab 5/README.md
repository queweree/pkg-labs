# Clipping Studio — лабораторная работа 5

Интерактивное веб-приложение по теме **«Алгоритмы отсечения отрезков и многоугольников»**. Не требует сборки, фреймворков и сервера: открывается как обычный `index.html`, поэтому подходит для GitHub Pages.

**Вариант 11.** По умолчанию для отрезков выбран Лианг–Барски, для выпуклого многоугольника — Сазерленд–Ходжман. Для сложных контуров есть обобщённый Уайлер–Атертон.

## Что реализовано

### Отрезки

- **Сазерленд–Коэн** через явное уравнение прямой `A·(x − x₀) + B·(y − y₀) = 0` и 4-битные коды вершин.
- **Лианг–Барски** через параметрическое задание `P(t) = P₀ + t·d`, ограничения `p/q` и интервал `t ∈ [0, 1]`.
- **Сайрус–Бек** через внутренние нормали выпуклого отсекателя и неравенства `n·(P(t) − F) ≥ 0`.
- Общий интерфейс: выбор метода, сравнение результатов, счётчики умножений, делений, сложений и сравнений, среднее время.
- Четырёхбитный код AABB отбрасывает габариты вне окна до вычисления пересечений.

### Многоугольники

- **Уайлер–Атертон** со вставкой общих узлов пересечений в обе границы и обходом дуг между ними.
- Поддержка **вогнутых** фигур, **дыр**, нескольких изолированных частей.
- **Самопересечения и совпадающие рёбра** разбиваются на дуги. Правило чётности определяет, где проходит граница заполненной области. Так обрабатываются пентаграмма, «бант» и вырезы, выходящие к краю окна.
- Ориентация: внешние контуры — CCW, дыры — CW; заливка Canvas выполняется правилом `even-odd`.
- Пресеты: вогнутый L-профиль, фигура с дырой, самопересекающаяся звезда, U-контур с распадом на две части.
- Вершины контура можно перетаскивать; окно двигается и масштабируется; экспорт результата в SVG.

### Производительность

- Четыре дерева **Quadtree**, по одному на каждую движущуюся группу (`capacity = 64`, глубина 3…10).
- База из **500 000 отрезков** с кластерным и равномерным распределением; сегменты хранятся по AABB.
- В живом режиме движутся окно и все четыре группы. Запрос выполняется в локальных координатах каждой группы, а кадр собирается из кэшированных слоёв и видимых частей. Интерфейс измеряет query + clip и частоту кадров.
- Замеры:
  - время от максимальной глубины дерева (4…10) на 500 000 отрезков;
  - время от плотности данных (25k…500k): Quadtree против полного перебора.
- Графики строятся по фактическим замерам. Замер плотности сверяет число видимых частей с полным перебором в каждом положении окна и групп.

### Устойчивость и тесты

- Геометрический допуск `EPS = 10⁻⁷` применяется в мировых координатах, в том числе к расстояниям при сшивке контуров.
- Точка на границе окна считается видимой.
- Отрезок нулевой длины внутри окна возвращается вырожденным результатом (точкой).
- Встроенный набор из **24 тестов** проверяет границы, вырожденные отрезки, промах рядом с углом, самопересечения, распад контура и положение окна внутри дыры.

## Запуск

```bash
# просто открыть файл
open index.html
```

Или запустить любой статический сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000/index.html
```

## Публикация на GitHub Pages

Репозиторий уже содержит workflow `.github/workflows/deploy.yml`, который публикует корень репозитория. Достаточно закоммитить папку `pkg lab 5` и обновлённый корневой `index.html`:

```bash
git add "pkg lab 5" index.html
git commit -m "added lab 5"
git push
```

После пуша GitHub Actions пересоберёт Pages. Ссылка на лабораторную появится в корневом каталоге `PKG Labs`.

## Формат входного файла

```text
n
x1_1 y1_1 x2_1 y2_1
...
x1_n y1_n x2_n y2_n
xmin ymin xmax ymax
```

Комментарии `#...`, запятые и точки с запятой допускаются. Пример — [`samples/segments.txt`](samples/segments.txt).

## Управление

- **Окно**: тянуть за внутреннюю область; ручки по сторонам и углам меняют размер.
- **Поле**: колесо мыши — масштаб, перетаскивание фона — панорама, `↺` — вписать данные.
- **Отрезки**. Включите **✎** на основном поле. Тяните линию целиком для переноса или один из концов для изменения длины и угла.
- **Метод**: переключатель в панели параметров или карточки алгоритмов.
- **Многоугольники**: пресеты, редактирование вершин (`✎`), изменение окна, экспорт SVG.
- **500 000**: кнопка «Подготовить 500k», затем «Живой режим». Кнопки «Замер глубины» и «Замер плотности» строят графики.
- **Тесты**: перезапуск встроенного набора, статус каждого кейса.

## Примечания

- Таймеры в браузере имеют ограниченное разрешение; для коротких наборов время усредняется по серии прогонов.
- Замеры зависят от браузера, CPU, фоновой нагрузки и размера окна. Указанные в отчёте значения — один контрольный запуск, а не гарантированная константа.
- Quadtree может хранить один отрезок в нескольких квадрантах, если его AABB пересекает границу; при запросе дубликаты отсекаются меткой `_stamp`.
- Уайлер–Атертон проверяет пары входных рёбер, затем определяет заполнение с обеих сторон каждой полученной дуги. Стоимость растёт с числом рёбер и пересечений.
