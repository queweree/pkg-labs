Три подхода к отрезку

Структурный, параметрический и выпуклый алгоритмы на одних и тех же входных данных.

ε 10⁻⁷счётчики операций
STRUCTURAL01

Сазерленд–Коэн

Четырёхбитный код вершины. Прямая задаётся явно уравнением A·(x − x₀) + B·(y − y₀) = 0, пересечения берутся из него.

A = y₂ − y₁ · B = x₁ − x₂code ∈ {LEFT, RIGHT, BOTTOM, TOP}
O(n + k)branch & clip
PARAMETRIC02

Лианг–Барски

Отрезок P(t) = P₀ + t·d. Четыре границы окна дают ограничения на параметр t ∈ [0, 1].

p = [−dₓ, dₓ, −d_y, d_y]q = [x₀−xmin, xmax−x₀, y₀−ymin, ymax−y₀]r = q / p → t₀ = max(t₀, r), t₁ = min(t₁, r)
O(1)4 границы
VECTOR03

Сайрус–Бек

Для каждой границы выпуклого отсекателя — внутренняя нормаль. Неравенство n·(P(t) − F) ≥ 0 задаёт интервал параметра.

f(t) = n·(P₀ − F) + t · n·dn·d > 0 → нижняя границаn·d < 0 → верхняя граница
O(k)k = 4 границы

MEASUREMENT NOTE

Что именно измеряется

На одинаковых положениях окна и групп замеряются запрос, AABB-префильтр и отсечение методом Лианга–Барски. Подготовка окна, отрисовка базового слоя и обновление DOM исключены. На результат влияют браузер, CPU и фоновая нагрузка.
