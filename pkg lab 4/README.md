# Дискретная графика

Статическое веб-приложение для изучения растровых алгоритмов. Проект не требует сборки и сторонних библиотек.

## Запуск

Откройте `index.html` в современном браузере. Для публикации загрузите файлы в корень репозитория GitHub и включите GitHub Pages для ветки `main`.

## Файлы

- `index.html` — структура интерфейса.
- `styles.css` — оформление и адаптивная раскладка.
- `app.js` — логика приложения.
