# Дискретная графика

Статическое веб-приложение для визуализации базовых алгоритмов растеризации. Проект работает без сборки, сервера и сторонних библиотек.

## Возможности текущей версии

- Пошаговый алгоритм и ЦДА для отрезка.
- Обобщённый алгоритм Брезенхема для всех направлений.
- Алгоритм Брезенхема для окружности с 8-кратной симметрией.
- Виртуальный двумерный растр на основе `Float32Array`.
- Сетка, целочисленные координаты, оси, масштабирование и ввод точек мышью.
- Отображение числа заполненных ячеек и времени вычисления.
- Трассировка заполненных пикселей и экспорт текущего изображения в PNG.

## Локальный запуск

Откройте `index.html` в современном браузере. Все пути относительные, сборка не требуется.

## GitHub Pages

1. Загрузите файлы проекта в корень GitHub-репозитория.
2. Перейдите в **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и каталог `/(root)`.
4. Сохраните настройки и откройте опубликованный адрес.

## Привязка координат к сетке

Координаты целые. Каждой паре `(x, y)` соответствует одна ячейка массива. Для сетки шириной `W` и верхней координаты `yMax` индекс массива вычисляется как `row = yMax - y`, `column = x - xMin`, `index = row * W + column`. При отображении ячейка просто увеличивается до квадрата на экране; сам алгоритм не рисует примитивы средствами Canvas.

## Структура

- `index.html` — интерфейс.
- `styles.css` — оформление.
- `app.js` — виртуальный растр, алгоритмы и отрисовщик.
- `report.md` — краткое описание формул и примеры вычислений.


## Сглаживание линий

Добавлен алгоритм Ву. Дробная часть идеальной координаты распределяет интенсивность между двумя соседними пикселями; виртуальный растр хранит значение интенсивности от 0 до 1, а не только булев флаг.


## Дуги Кастла–Питвея

Добавлена целочисленная трассировка параболической дуги по конечным разностям конического сечения. Три контрольные точки задаются в редакторе; если точки коллинеарны, отображается ломаная через контрольную точку.


## Стресс-тест

Модуль заранее генерирует 100 000 отрезков, покрывающих все октанты, и 50 000 окружностей разного радиуса. Высокоточные замеры через `performance.now()` суммируются только вокруг циклов растеризации в отдельный массив 512 × 512; подготовка тестовых данных, обновление статуса и паузы между пакетами не входят во время ядра.


После завершения теста автоматически строятся два графика: накопленное время от числа обработанных примитивов и время обработки 1 000 отрезков от длины линии. Сравнение методов выполняется повторным запуском теста после выбора другого алгоритма.
