# Raster Studio

Интерактивная лаборатория дискретной графики: пошаговый алгоритм, ЦДА, Брезенхем, Брезенхем для окружности, антиалиасинг Ву, целочисленная трассировка параболической дуги по схеме Кастла–Питвея и стресс-тестирование виртуального растра.

## Запуск локально

Приложение не требует сборки, Node.js, библиотек или сервера. Откройте `index.html` в современном браузере. Для публикации лучше использовать GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `app.js`, `README.md`, `report.md` и `THIRD_PARTY_NOTICES.md`.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Дождитесь публикации и откройте ссылку, которую покажет GitHub Pages.

Никаких путей с абсолютным префиксом `/` приложение не использует, поэтому оно также работает в Pages-проекте вида `https://username.github.io/repository/`.

## Файлы

- `index.html` — структура интерфейса и разделы с теорией.
- `styles.css` — адаптивное оформление.
- `app.js` — виртуальный растр, реализации алгоритмов, визуализация, интерактивные координаты, тесты производительности и графики.
- `report.md` — сопровождающий аналитический отчёт и расчётный пример.
- `THIRD_PARTY_NOTICES.md` — сведения об источнике реализации алгоритма Кастла–Питвея.

## Возможности

- Отрезки: пошаговый метод, ЦДА, Брезенхем и сглаживание Ву.
- Окружности: целочисленный алгоритм Брезенхема с 8-кратной симметрией.
- Параболическая дуга: целочисленная трассировка конического сегмента по конечным разностям Кастла–Питвея.
- Виртуальный числовой растр `Float32Array`; вычислительное ядро не использует Canvas API.
- Сетка с целыми координатами, осями, делениями, подписями, изменением масштаба и экспортом PNG.
- Проверка восьми октантов, просмотр интенсивности пикселей и число заполненных ячеек.
- Стресс-тест: 100 000 отрезков во всех октантах и 50 000 окружностей. Данные готовятся до запуска таймера; замеряется время заполнения отдельного виртуального растра 512 × 512, а графики строятся после обработки.
- График времени от числа примитивов и график времени от длины отрезка.
- Измеряемое время зависит от браузера, устройства и фоновой нагрузки; готовые фиктивные значения не подставляются.

## Как пользоваться

1. Выберите объект и алгоритм в редакторе.
2. Введите целочисленные координаты или кликайте по сетке. Для отрезка два клика задают начало и конец; для дуги три клика задают начало, контрольную точку и конец.
3. Нажмите **Построить**. В карточках появятся число уникальных ячеек и время вычисления, а рядом — краткая формула и трассировка пикселей.
4. Для проверки октантов нажмите **Показать 8 октантов**.
5. Выберите алгоритм отрезка и запустите **стресс-тест**. Для сравнения повторите тест с другими алгоритмами. После каждого теста графики и результаты пересчитываются.
6. Скачайте актуальный отчёт из раздела «Теория и аналитический отчёт». Он включает измерения, которые были выполнены в текущей вкладке.

## Примечание о замерах

Таймер включает вызовы выбранного алгоритма и записи пикселей в тестовый массив. Подготовка случайных примитивов, перерисовка пользовательского интерфейса, построение графиков и ожидание между пакетами исключены из суммируемого времени. На итог влияют аппаратная платформа, движок JavaScript и фоновая нагрузка.
