# Краткий аналитический отчёт

## Виртуальный растр

Модель хранит матрицу интенсивностей в `Float32Array`. Значение `0` означает незакрашенную ячейку; положительное значение — заполненную ячейку. Алгоритмы изменяют числовой массив, а визуализация считывает готовые значения и рисует увеличенные квадраты.

Для сетки с `W` столбцами, минимальной координатой `xMin` и верхней координатой `yMax`:

- `column = x - xMin`;
- `row = yMax - y`;
- `index = row * W + column`.

Ось X направлена вправо, ось Y математически направлена вверх. Поэтому большие `y` располагаются выше на экране.

## Пошаговый алгоритм

Для отрезка A(x₀, y₀) — B(x₁, y₁) вычисляются `dx = x₁ − x₀`, `dy = y₁ − y₀`. После приведения ведущей координаты к X используется наклон `m = dy/dx`; на каждой позиции находится `y = round(y₀ + m(x − x₀))`. Для крутых линий X и Y меняются местами.

## Цифровой дифференциальный анализатор (ЦДА)

`N = max(|dx|, |dy|)`, `xStep = dx/N`, `yStep = dy/N`. Координаты накапливаются с постоянным дробным шагом и округляются к ближайшей ячейке. Для нулевого отрезка записывается единственная точка.

## Брезенхем для отрезка

Используется обобщённая целочисленная схема: `dx = |x₁ − x₀|`, `dy = −|y₁ − y₀|`, `err = dx + dy`. На каждой итерации вычисляется `e2 = 2 * err`, после чего независимо проверяются условия шага по X и Y. Знаки приращений позволяют строить линии во всех восьми октантах.

## Брезенхем для окружности

Для одного октанта используются стартовые значения `x = 0`, `y = r`, `d = 3 − 2r`. Положение следующего пикселя выбирается по целочисленной ошибке. Каждая точка отражается относительно осей и диагоналей, что даёт до восьми симметричных точек за итерацию.

## Пример: A(2, 1) → B(9, 5)

`dx = 7`, `dy = 4`, `N = max(7, 4) = 7`. Для ЦДА приращения равны `xStep = 1` и `yStep = 4/7 ≈ 0,5714`. После округления последовательность пикселей:

`(2,1), (3,2), (4,2), (5,3), (6,3), (7,4), (8,4), (9,5)`.

У Брезенхема решение основано на целочисленной ошибке. При тех же конечных точках он проходит те же ячейки, избегая деления с плавающей точкой в основном цикле.

## Сравнение производительности

Все три алгоритма отрезка имеют линейную сложность `O(N)`, где `N = max(|dx|, |dy|)`. Пошаговый алгоритм повторно вычисляет выражение прямой и округляет результат; ЦДА накапливает дробные координаты; Брезенхем обновляет целочисленную ошибку только сложением и сравнением. Поэтому у Брезенхема часто ниже стоимость одной итерации, но фактическое время зависит от браузера, процессора и числа записей в растр. Точные сравнения следует делать по измерениям в одном окружении.


## Алгоритм Ву

Для дробной координаты `y = floor(y) + f` интенсивности двух соседних ячеек вычисляются как `1 − f` и `f`. На концах учитывается покрытие по X. В отличие от бинарной растеризации, соседние пиксели получают частичную интенсивность, что визуально уменьшает ступенчатость линии.
